# Калькулятор на Java

Учебный консольный калькулятор с поддержкой последовательных вычислений.

## Возможности

- Сложение, вычитание, умножение и деление.
- Использование результата в следующем вычислении.
- Проверка деления на ноль и некорректного ввода.
- Сброс вычислений командой `C`.
- Завершение работы командой `S`.

Команды работают без учёта регистра. Дробные числа вводятся через точку.

## Запуск

Откройте проект в IntelliJ IDEA с настроенным JDK 17 или выше.
Запустите метод `main` в файле `src/Calculator.java`.

## Пример

Вводите числа и операции через пробел или нажимайте Enter после каждого значения.

```text
2 + 3
Результат: 5.0

* 4
Результат: 20.0
```
